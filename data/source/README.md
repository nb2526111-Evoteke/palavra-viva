# Fonte da Bíblia

Arquivos usados por `npm run db:setup` e `npm run bible:import`.

- `almeida-livre.sqlite` — Bíblia Livre (BLIVRE), 66 livros, 1.189 capítulos e
  31.102 versículos.
- `metadata.json` — metadados de licença, fonte e estatísticas.
